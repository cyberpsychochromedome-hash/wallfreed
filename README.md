# Wallpaper Studio
Layered wallpaper creator + library. See the chat tutorial for the GitHub build steps.
Quick version: put this folder in a PUBLIC GitHub repo, then create a Release tagged v0.2.0.
GitHub Actions builds WallpaperStudioSetup.exe and attaches it to the release.
Local test (Windows): install Node 20, then `cd app && npm install && npm start`
(behind-icons mode needs app/bin/attach.exe, which only the GitHub build creates).
